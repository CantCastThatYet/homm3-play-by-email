Heroes Post for HotA
====================

Heroes Post adds a button to HotA's multiplayer screen: online games through a server,
which you can leave and return to at any time.

It works with HotA 1.8.1 and the HD Mod that comes with it. With any other version the
button does not appear.

The easy way: run HeroesPost-Setup.exe. It finds HotA, checks the version and installs.

By hand:
1. Close HotA.
2. Copy version.dll and HeroesPost.Native.dll into the HotA folder (the one with
   h3hota HD.exe). If that folder already has a version.dll, it belongs to another mod:
   Heroes Post cannot be installed beside it.
3. Start HotA, open its multiplayer screen and press Heroes Post, below the connection
   types. The first time, it asks for the address of your server (whoever runs it can tell
   you); then sign in or register. The Server button in the lobby changes the address.

To remove it, delete version.dll and every file starting with HeroesPost. from the HotA folder.

Project: https://github.com/CantCastThatYet/homm3-play-by-email


Heroes Post для HotA
====================

Heroes Post добавляет кнопку на экран сетевой игры HotA: онлайн-игры через сервер,
из которых можно выйти и вернуться в любой момент.

Работает с HotA 1.8.1 и входящим в неё HD Mod. С другими версиями кнопка не появится.

Проще всего: запустите HeroesPost-Setup.exe. Он сам найдёт HotA, проверит версию и
установит мод.

Вручную:
1. Закройте HotA.
2. Скопируйте version.dll и HeroesPost.Native.dll в папку HotA (где лежит h3hota HD.exe).
   Если там уже есть version.dll, он от другого мода: рядом с ним Heroes Post установить
   нельзя.
3. Запустите HotA, откройте экран сетевой игры и нажмите Heroes Post под типами подключения.
   В первый раз он спросит адрес вашего сервера (его скажет тот, кто держит сервер); затем
   войдите или зарегистрируйтесь. Кнопка Server в лобби меняет адрес.

Чтобы удалить мод, удалите из папки HotA файл version.dll и все файлы, имена которых
начинаются с HeroesPost.
